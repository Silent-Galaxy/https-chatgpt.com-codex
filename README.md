# SteamShop (نمونه فروشگاه استیم)

این ریپو شامل یک نمونه‌ی کامل از رابط فروشگاه محصولات استیم است که با **HTML/CSS/JS** ساخته شده و برای استفاده در CodePen هم مناسب است.

## اجرا
1. فایل `index.html` را مستقیم در مرورگر باز کنید.
2. یا آن را در CodePen داخل بخش HTML قرار دهید (CSS و JS همگی داخل همان فایل هستند).

## ویژگی‌ها
- طراحی مدرن RTL مناسب زبان فارسی
- بخش محصولات استیم (والت، گیفت کارت، کلید بازی)
- جستجو و فیلتر دسته‌بندی
- سبد خرید تعاملی با جمع کل
